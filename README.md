# Leading from the Middle — GitHub Pages site

A responsive, static HTML/CSS resource for mid-level managers.

## Files
- `index.html` — complete article and page structure
- `styles.css` — responsive visual design
- `assets/vincent-hands-on.jpg` — original uploaded hands-on technical photo

## Publish with GitHub Pages
1. Create a GitHub repository, for example `leading-from-the-middle`.
2. Upload the contents of this folder (not the parent folder) to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

No build tools, JavaScript frameworks, or external libraries are required.
